## 🚀 Featured Project: TechPulse Intelligence

Located in [`techpulse-intelligence/`](./techpulse-intelligence):

- **🏛️ Classical × Synthwave Aesthetic**: Michelangelo David 3D bust perspective with real-time HTML5 Canvas Web Audio synthesizer frequency visualizer.
- **🛡️ Autonomous Intelligence Gathering**: Ingests CISA Known Exploited Vulnerabilities (KEV), EPSS exploit probability scores, Hugging Face AI papers, and GitHub velocity repositories.
- **⚡ AI Synthesis**: Distills daily signals into executive briefings and strategic signals using Google Gemini.
- **📰 Syndication & Automation**: Automated RSS 2.0 / Atom feed generators, Markdown archive publishing, and scheduled daily execution.

To run TechPulse locally:
```bash
# Frontend
cd techpulse-intelligence/web
npm install
npm run dev

# Intelligence Pipeline
cd techpulse-intelligence
pip install -r requirements.txt
python main.py run
```
